# البدء محليًا

المشروع تحت التطوير. الواجهة في `apps/web` والباك إند الوحيد في `backend/`. تم حذف `apps/api` القديم، ولا يتم نقل حساباته أو بياناته تلقائيًا. خدمة Python مجرد فحص صحة ولا تشغّل تحليلًا.

استخدم Node >=22.13 وpnpm 11.25.0، ثم من جذر المشروع:

```sh
pnpm install --frozen-lockfile
pnpm setup:local
```

راجع ملف `.env` الخاص: اضبط `MONGODB_URI` واسم قاعدة البيانات المقصودة `MONGODB_DATABASE` و`JWT_SECRET` و`APP_ORIGIN`. الإعداد يحافظ على الملف الموجود ولا يغيّر قاعدة البيانات أو الأسرار. يلزم Atlas أو replica set للمعاملات. لا تحذف البيانات القديمة؛ نماذج ObjectId الجديدة ليست تحويلًا تلقائيًا لحسابات UUID القديمة.

```sh
pnpm db:check
pnpm db:setup
pnpm dev
```

افتح `http://127.0.0.1:5173/`. الأمر يشغّل الواجهة والباك إند فقط، وإيقافه يوقف مجموعته دون إغلاق برامج أخرى. التسجيل يسجّل الدخول مباشرة؛ تأكيد البريد وإعادة إرساله غير متاحين. استعادة كلمة المرور في وضع `MAIL_MODE=file` تكتب رسالة JSON خاصة مباشرة في `.local/mail`، بلا عامل بريد منفصل؛ افتح رابط `text` للرسالة الصحيحة. هذا ليس إرسالًا لصندوق بريد حقيقي.

واجهات إدارة الاستبيانات موجودة في الباك إند، لكن جمع الردود والتحليلات والذكاء الاصطناعي وربط بقية الواجهة ما زال قيد التطوير. بيانات العرض التجريبية تحت `/preview/`. اقرأ [README](../README.md) و[عقد API](api/README.md) للتفاصيل والقيود.
